# 💡 프로젝트 개요
## 배경 및 목표
- ONE이란? 삼성전자의 오픈소스, 온디바이스 AI 풀스택 프레임워크입니다.
- ONE을 통해 다양한 AI 모델을 스마트폰, TV, 냉장고와 같은 엣지 디바이스 환경에서 사용할 수 있습니다.
- 본 프로젝트에서는 [LLM을 위한 연산들이 Dynamic Shape에 대해 Shape Inference를 지원하도록 개선하는 이슈](https://github.com/Samsung/ONE/issues/13697)를 해결하는것을 목표로 합니다.
